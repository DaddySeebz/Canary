# CANARY website asset pack

This pack includes web-ready logo variants derived from the approved logo image.

## Included

### PNG
- `canary-logo-stacked-dark.png` — original stacked lockup on black
- `canary-logo-stacked-transparent.png` — stacked lockup on transparent
- `canary-logo-horizontal-dark.png` — horizontal lockup on black
- `canary-logo-horizontal-transparent-dark.png` — horizontal lockup for dark backgrounds
- `canary-logo-horizontal-transparent-light.png` — horizontal lockup for light backgrounds
- `canary-icon-gold-transparent.png` — icon only, transparent, detailed
- `canary-icon-gold-flat-transparent.png` — icon only, simplified flat gold
- `canary-icon-white-flat-transparent.png` — monochrome white icon
- `canary-icon-black-flat-transparent.png` — monochrome black icon
- `canary-wordmark-white-transparent.png` — wordmark only for dark backgrounds
- `canary-wordmark-black-transparent.png` — wordmark only for light backgrounds
- `canary-wordmark-gold-transparent.png` — optional gold wordmark

### SVG
- `canary-icon-mark.svg` — monochrome vector icon using `currentColor`
- `canary-icon-mark-gold.svg` — gold vector icon
- `canary-wordmark.svg` — monochrome vector wordmark using `currentColor`
- `canary-wordmark-white.svg`
- `canary-wordmark-black.svg`
- `canary-logo-stacked-dark.svg`
- `canary-logo-stacked-light.svg`
- `canary-logo-horizontal-dark.svg`
- `canary-logo-horizontal-light.svg`

### Favicon

## Note
The SVG files are clean monochrome vector traces of the approved artwork for practical web use.
The full-color metallic logo assets remain raster-derived from the approved concept image.
